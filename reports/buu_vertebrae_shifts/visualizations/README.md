# Визуализация пяти промежутков BUU

Создано 15 ноября 2026 года. Для пяти снимков случайной выборки без повторов
(seed=42) построены все пять замеров по исходным COCO-координатам.
Каждый PNG содержит только исходный снимок и пять построений
L1–L2, L2–L3, L3–L4, L4–L5, L5–S1. Дополнительные увеличения убраны.
Подписи процентов вынесены в сторону от линий и связаны с замерами
тонкой выноской. Сохраняется полный кадр и соотношение сторон снимка.

## Построение

- Бирюзовая сплошная линия — верхняя пластина нижнего позвонка `AB`.
  `A` — передняя точка, `B` — задняя. Точками показано продолжение прямой.
- Красная точка `P` — нижняя задняя точка верхнего позвонка.
- Розовый пунктир `PQ` — перпендикуляр к прямой `AB`.
- Жёлтый ромб `Q` — основание перпендикуляра; белый уголок показывает прямой угол.
- Жёлтый отрезок `QB` — измеряемое смещение. Стрелка направлена от `Q` к `B`.
- Подпись каждой пары содержит её название и `100*S` со знаком.
  Подпись отнесена от построения на 44 типографских пункта с дополнительным
  отступом вдоль X на 12% длины пластины; у правого края она переносится влево.
  Длины в исходных пикселях доступны в JSON построений.

```text
u = (B - A) / |B - A|
Q = A + dot(P - A, u) * u
L = |B - A|
d = dot(B - Q, u)
S = d / L
```

Плюс означает переднее смещение задней точки верхнего позвонка,
минус — заднее. Проекция может находиться за пределами отрезка `AB`.
Для очень коротких смещений точки `Q` и `B` визуально близки; численное
значение всё равно рассчитано без округления и подписано до сотых процента.
Невалидная пара отмечается `NaN` с причиной; остальные пары отображаются.

## Запуск

Из корня репозитория, пять снимков с воспроизводимой случайной выборкой:

```bash
MPLCONFIGDIR=/tmp/cv-matplotlib conda run --no-capture-output -n mmpose \
  python tools/visualize_vertebrae_shifts.py \
  --annotations data/LumbarCoco2000/annotations \
  --images-dir data/LumbarCoco2000/images \
  --output-dir reports/buu_vertebrae_shifts/visualizations \
  --count 5 --seed 42
```

Конкретные снимки выбираются по COCO image_id:

```bash
MPLCONFIGDIR=/tmp/cv-matplotlib conda run --no-capture-output -n mmpose \
  python tools/visualize_vertebrae_shifts.py \
  --image-ids 2066 1229 1767 230 1218
```

`--image-ids` имеет приоритет над `--count`. По умолчанию используются
аннотации и изображения BUU-2000. `--annotations` принимает файлы и/или
директории, `--dpi` задаёт разрешение (по умолчанию 140).

[Скрипт визуализации](../../../tools/visualize_vertebrae_shifts.py) переиспользует
проверку разметки, индексы точек и расчёт из анализатора. Модель не требуется.
[JSON построений](visualization_measurements.json) содержит исходные координаты
`P,A,B,Q`, длины, проценты, причины невалидности и сведения об источниках.

Все 25 значений совпадают с [CSV датасета](../vertebrae_shifts.csv).
Проверены геометрия проекций, размеры PNG и хеши входных аннотаций.
25 тестов анализатора и визуализатора прошли:

```bash
MPLCONFIGDIR=/tmp/cv-matplotlib conda run --no-capture-output -n mmpose \
  python -m unittest discover -s tests -p 'test_*vertebrae_shifts.py' -v
```
